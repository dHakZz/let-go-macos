# Changelog

## 0.1.1 — Unreleased

- Make Watch Until Free and Auto-Eject When Ready available to everyone.
- Remove the locked supporter preview and all payment-gated language.
- Show automation controls only after Let Go finds a process holding the selected item.
- Keep financial support optional and hide the support link when no destination is configured.
- Add a Developer ID signing and Apple notarization workflow for release builds.

## 0.1.0 — September 5, 2026

Initial public release.

- Inspect a file, folder, or mounted drive to find processes using it.
- Show open paths grouped by process.
- Reveal an open item in Finder.
- Request that a user-owned process quit.
- Safely eject a clear external volume.
- Choose an item by dropping it into the app or clicking the drop area.
- Reset the current task by clicking the Let Go icon.
- Open Suggestions, Privacy & Safety, and What’s New from the main window.
- Preview locked Watch Until Free and Auto-Eject When Ready supporter features.
- Use a universal Intel and Apple silicon build on macOS 13 or later.
